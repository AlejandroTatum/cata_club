# Evidencia — Auditoría UI/UX 2026-08-29

Esta rama es huérfana: no tiene historia de commits del proyecto ni código fuente.
Existe únicamente para alojar las capturas de pantalla que documentan los hallazgos
de la auditoría de UI/UX realizada el 2026-08-29 (5 roles, 35 rutas, desktop
1440x900 y móvil 390x844, axe-core WCAG 2.1 AA + sondas de layout propias).

Los issues de GitHub abiertos a partir de esa auditoría enlazan directamente a las
imágenes de esta rama.

Las capturas provienen del stack local de QA, con datos de fixtures sembrados
(seed data). Ninguna imagen contiene datos de personas reales.
